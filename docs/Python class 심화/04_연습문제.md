## 📖 원본 코드와 수업 메모

### 문제 조건

점수는 0~100점으로 제한하며, 점수가 없을 때 평균과 최고 점수는 0을 반환하도록 요구한다.

**원본 수업 메모**

> - 조건 :
> - Student class 만들기
> - 속성 : name (public), __scores (private, 빈 리스트)
> - add_score(score) : 점수 추가, 0~100 범위가 아니면 "유효하지 않은 점수입니다" 출력
> - get_average() : 평균 점수 반환, 점수가 없으면 0 반환
> - get_highest() : 최고 점수 반환
> - get_scores() : 전체 점수 리스트 반환
> - __str__ : "이름 (평균: 00.0점, 최고: 00점)" 형태로 출력

### 작성한 코드와 테스트

`get_average()`, `get_highest()`, `get_scores()`로 성적을 조회하고 `__str__()`로 학생별 정보를 출력한다.

```python
class Student:
    def __init__(self, name):
        self.name = name
        self.__scores = []
    
    def add_score(self, score):
        if score < 0 or score > 100:
            print("유효하지 않은 점수입니다.")
        self.__scores.append(score)

    def get_average(self):
        if not self.__scores:
            return 0
        return sum(self.__scores) / len(self.__scores)
    
    def get_highest(self):
        if not self.__scores:
            return 0
        return max(self.__scores)

    def get_scores(self):
        return self.__scores    
    
    def __str__(self):
        return f"{self.name} (평균 : {self.get_average()}, 최고 : {self.get_highest()})"


A = Student("A")
A.__scores = [1,2,3,4]
print(A.__scores) # ??

A.add_score(50)
A.add_score(87.4)
A.add_score(-1) # 유효하지 않은 점수입니다.
print(A.get_average())
print(A.get_highest())
print(A)
  
```

## ✅ 핵심 정리 및 확인 사항

원본 코드는 수정하지 않았다. 아래 항목은 읽거나 실행할 때 확인하면 좋은 부분이다.

- `add_score()`에서 범위를 벗어났다는 메시지를 출력한 후에도 `self.__scores.append(score)`가 실행된다. 원본 그대로라면 -1점이 목록에 추가된다.
- `get_scores()`가 내부 리스트 자체를 반환하므로 호출자가 반환값을 수정할 수 있다. `list(self.__scores)` 등으로 사본을 반환하면 캡슐화를 강화할 수 있다.
- `A.__scores = [...]`는 이름 맹글링된 원래 점수 리스트를 교체하지 않고 별도 속성을 만든다.
