### 배포 방식 업그레이드

두 가지 배포 방식
            gh-pages branch 방식 / github actions 전용 방식(단일 branch)
Branch      main + gh-pages       main 하나
Pages 설정   Deploy from a branch     GitHub Actions
workflow 파일   직접 작성           GitHub 제공 템플릿 사용


전환 순서
기존 workflow 파일 삭제
Github Pages 설정 변경
새 workflow 파일 생성
workflow 파일 수정
