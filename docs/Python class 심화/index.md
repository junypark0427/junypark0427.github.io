## 안내

- **원본 우선:** 코드와 주석은 수정하거나 삭제하지 않았다.
- **가벼운 보충:** `super()`·MRO·Mixin처럼 맥락이 필요한 부분에만 짧게 덧붙였다.
- **오류 표시:** 학습 코드에서 확인할 사항은 각 문서 마지막에 별도로 적었다.
- **실행 주의:** 일부 파일은 같은 클래스를 여러 차례 정의하므로, 각 코드 블록을 독립 실행하는 자료가 아니다.
