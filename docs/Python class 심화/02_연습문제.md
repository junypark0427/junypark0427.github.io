### 작성한 코드

`slime`, `Dragon`은 공격을 새로 정의하고, `Mimic`, `Ghost`는 `super().attack()`의 결과 앞에 설명을 붙인다.

```python
class Monster:
    def __init__(self, name, hp, attack_power):
        self.name = name
        self.hp = hp
        self.attack_power = attack_power

    def attack(self):
        return f"{self.name} attacks!! Deals {self.attack_power} damage"

class slime(Monster):
    def attack(self):
        return f"{self.name} sticks!! Deals {self.attack_power*0.5} damage"

class Dragon(Monster):
    def attack(self):
        return f"{self.name} Breathes fire!! Deals {self.attack_power*2} damage"

class Mimic(Monster):
    def attack(self):
        return "Thought it was a treasure chest, didn't you?" + super().attack()

class Ghost(Monster):
    def attack(self):
        return "유령이라 공격이 매우 약해" + super().attack()

party = [slime("Slime", 100, 20), Dragon("Dragon", 100, 40), Mimic("Mimic", 100, 30)]
party.append(Ghost("Ghost", 50, 5))
for mem in party:
    print(mem.attack())
    print(" ")


        
```
