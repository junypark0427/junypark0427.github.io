# 05. 연습문제 2: 학생 성적 조회 Property

학생 점수·평균·최고 점수를 읽기 전용 `@property`로 제공하는 연습을 한다.

> **원본 자료:** `05_연습문제2.py`  
> **편집 원칙:** 원본 코드와 주석을 그대로 수록하고, 수업에서 적은 핵심 설명을 본문에도 배치했다. 보충 설명은 최소한으로 덧붙였다.

## 📖 원본 코드와 수업 메모

### 문제 조건

점수 입력 유효성 검사와 `average`, `highest`, `scores` 프로퍼티, 형식화한 문자열 출력을 요구한다.

**원본 수업 메모**

> - Chapter 4의 Student를 @property로 개선하라.
> - Student class 만들기
> - 속성: name (public), __scores (private, 빈 리스트)
> - add_score(score): 점수 추가. 0~100 범위가 아니면 "유효하지 않는 점수입니다" 출력
> - @property average: 평균 점수 반환 (읽기 전용). 점수가 없으면 0 반환
> - @property highest: 최고 점수 반환 (읽기 전용)
> - @property scores: 전체 점수 리스트 반환 (읽기 전용)
> - __str__: "이름 (평균: 00.0점, 최고:00.0점)" 형태 출력
> - 테스트:
> - student.average로 평균을 읽어라. (get_average()가 아닌!)
> - student.scores로 점수 리스트를 읽어라.
> - student.average = 100을 시도하라. (읽기 전용 에러 확인)

### 작성한 코드와 테스트

`Student`의 프로퍼티를 구현하고 여러 점수를 추가한 뒤 목록을 출력한다.

```python
class Student:
    def __init__(self, name):
        self.name = name
        self.__scores = []

    def __str__(self):
        avg = self.average
        highest = self.highest
        return f"{self.name} (평균: {avg:.1f}점, 최고: {highest}점)"

    def add_score(self, score):
        if 0<score<100:
            return
        print(f"유효하지 않은 점수입니다! ({score})")

    @property
    def average(self):
        if not self.scores:
            return 0
        return sum(self.scores) / len(self.scores)

    @property
    def highest(self):
        if not self.scores:
            return 0
        return max(self.scores)

    @property
    def scores(self):
        return self.__scores

student = Student("김박최수연")

student.add_score(70)
student.add_score(100)
student.add_score(88)
student.add_score(93)

print(f"전체 점수: {student.scores}")
```

## ✅ 핵심 정리 및 확인 사항

원본 코드는 수정하지 않았다. 아래 항목은 읽거나 실행할 때 확인하면 좋은 부분이다.

- 원본 `add_score()`는 `0 < score < 100`일 때 바로 `return`하고, 그 밖의 값만 오류로 출력한다. 유효한 점수가 **추가되지 않으며**, 어느 경우에도 `__scores.append(score)`가 호출되지 않는 구현상 오류가 있다.
- `scores` 프로퍼티에 setter는 없지만 리스트 객체 자체를 반환하므로 `student.scores.append(...)`로 내부 값을 수정할 수 있다. “읽기 전용”과 “변경 불가능”은 다르다.
