# Juny's Log

안녕하세요! **Juny's Log**에 오신 것을 환영합니다.

이곳은 제가 배우고, 경험하고, 생각한 것들을 자유롭게 기록하는 개인 공간입니다.

새롭게 알게 된 지식부터 직접 만들어 본 프로젝트, 흥미롭게 느낀 주제와 일상적인 생각까지 다양한 이야기를 담아가려고 합니다.

특정한 분야나 형식에 얽매이지 않고, 관심이 가는 것들을 탐구하며 그 과정에서 얻은 경험을 기록합니다.
