# 01. 웹사이트(Web Site)와 웹페이지(Web Page)

웹사이트를 만들기 전에, 웹페이지가 어떻게 구성되고 브라우저에 나타나는지부터 알아보자.

## 1. Web Site란? 🖥️

**Web Site(웹사이트)**는 인터넷에서 접속할 수 있는 여러 웹페이지와 콘텐츠를 모아 놓은 공간이다. 우리가 브라우저에서 보고 있는 화면 하나하나는 **Web Page(웹페이지)**라고 부른다.

예를 들어 블로그 전체는 웹사이트이고, 그 안의 개별 게시글이나 소개 페이지는 각각 웹페이지에 해당한다.

### Server와 Client

| 구분 | 역할 |
| --- | --- |
| **Server(서버)** | 웹사이트에 필요한 파일과 데이터를 보관하고, 요청에 따라 응답을 보낸다. |
| **Client(클라이언트)** | 웹사이트에 접속하는 쪽이다. 브라우저를 통해 서버에 요청하고 응답을 받아 화면에 표시한다. |

브라우저 주소창에 **URL(Uniform Resource Locator)**을 입력하면 해당 주소로 요청을 보낸다. 서버가 HTML, CSS, JavaScript 등의 리소스를 응답하면, 브라우저는 이를 해석해 웹페이지를 표시한다.

```text
Client ─────── Request ───────▶ Server
Client ◀────── Response ─────── Server
```

> 💡 **핵심:** 서버는 요청에 응답하고, 클라이언트는 받은 내용을 바탕으로 페이지를 보여 준다.

---

## 2. 웹페이지의 언어: HTML 🧱

**HTML(HyperText Markup Language)**은 웹 문서의 **구조와 내용**을 정의하는 마크업 언어다. 제목, 문단, 링크, 이미지처럼 페이지를 이루는 요소를 태그로 표현한다.

### 기본 HTML 예시

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <title>내 첫 페이지</title>
  </head>
  <body>
    <h1>안녕하세요</h1>
    <p>이게 web page입니다.</p>
  </body>
</html>
```

위 코드를 `index.html`로 저장하고 브라우저에서 열어 보면 제목과 문단이 나타난다.

자주 쓰이는 태그를 살펴보면 다음과 같다.

| 태그 | 의미 |
| --- | --- |
| `<html>` | HTML 문서 전체 |
| `<head>` | 문서 제목, 문자 인코딩 등 부가 정보 |
| `<body>` | 브라우저 화면에 표시할 내용 |
| `<h1>` | 큰 제목 |
| `<p>` | 문단 |

HTML만 작성해도 내용은 볼 수 있지만, 디자인과 동작은 별도로 추가할 수 있다.

---

## 3. 웹페이지의 디자인: CSS 🎨

HTML이 내용과 구조를 담당한다면, **CSS(Cascading Style Sheets)**는 그 내용을 **어떻게 보이게 할지** 결정한다.

예를 들어 글자색과 배경색, 버튼 모양, 요소 사이의 여백, 화면 배치 등을 CSS로 조절할 수 있다.

### CSS 예시

```css
body {
  background-color: #f5f5f5;
  color: #333333;
}

h1 {
  text-align: center;
}
```

이 스타일을 적용하면 페이지 배경이 연한 회색으로 바뀌고, 제목이 가운데에 정렬된다.

CSS는 HTML 문서 안의 `<style>` 태그에 작성할 수도 있고, `style.css` 같은 별도 파일에 저장해 연결할 수도 있다.

> 💡 **기억하기:** HTML은 *무엇을 보여 줄지*, CSS는 *어떻게 보여 줄지*를 정한다.

---

## 4. 웹페이지의 동작: JavaScript ⚙️

**JavaScript**는 웹페이지에 **상호작용과 동작**을 추가하는 프로그래밍 언어다.

버튼을 눌렀을 때 메시지를 띄우거나, 사용자의 입력에 따라 내용을 바꾸는 작업이 대표적이다.

### JavaScript 예시

HTML에 버튼이 있다고 가정하자.

```html
<button id="hello-button">눌러 보기</button>
```

여기에 다음 JavaScript를 연결할 수 있다.

```javascript
document.querySelector("#hello-button").addEventListener("click", () => {
  alert("안녕하세요!");
});
```

이제 버튼을 클릭하면 알림 창이 나타난다. JavaScript 코드는 HTML의 `<script>` 태그 안에 작성하거나 별도의 `.js` 파일로 분리할 수 있다.

참고로 모든 웹페이지에 JavaScript가 반드시 필요한 것은 아니다. 간단한 문서나 안내 페이지는 HTML과 CSS만으로도 만들 수 있다.

---

## 5. 정리 📝

| 기술 | 담당하는 역할 | 예시 |
| --- | --- | --- |
| **HTML** | 구조와 내용 | 제목, 문단, 링크 |
| **CSS** | 디자인과 스타일 | 색상, 여백, 레이아웃 |
| **JavaScript** | 상호작용과 동작 | 클릭 이벤트, 화면 내용 변경 |

세 기술이 함께 쓰이면 구조가 있고, 보기 좋으며, 사용자와 상호작용하는 웹페이지를 만들 수 있다.

### Local과 배포

`index.html` 파일을 직접 열면 **내 컴퓨터(Local)**에서도 페이지를 확인할 수 있다. 하지만 다른 사람도 인터넷으로 접속하게 하려면 웹페이지 파일을 온라인에 공개해야 한다. 이 과정을 **배포(Deployment)**라고 한다.

이후에는 GitHub Pages를 이용해 만든 웹사이트를 실제로 배포해 볼 것이다.
